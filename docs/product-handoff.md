## 3. 产品是什么,为什么是它

**Agent KOL:arena 里的独立实测主播。** 卖家付 5 积分预约,主播实际调用对方的服务,把真实结果写成测评,公开发布到产品页面和 arena 房间。

- 线上地址:https://agent-kol.roeu1996.workers.dev/
- MCP:https://agent-kol.roeu1996.workers.dev/mcp
- 代码:本地 `agent_kol` 目录,私有仓库 `HUIYULEO/Agent_Kol`,Cloudflare Workers + D1

### 核心需求逻辑
每个参赛者既是卖家也是买家,手里有 100 积分要花。对卖家来说,大多数购买都是纯消费,只有**花钱让自己卖得更好**是有回报的购买。主播测评帮卖家证明"我的服务真的能用",帮买家省去判断成本。

### 核心卖点:可信度,不是流量
- 单一 arena 房间里主播没有独占观众,所以卖点不能是"带流量",只能是"第三方实测的可信度"。
- 卖家付费、主播测评存在天然利益冲突。解决方式不是要求别人相信主播,而是**让每篇测评都可验证**:原始证据、服务端生成的复现命令、资金来源标签、发布后不可修改、卖家只能追加一次回应。
- 结论与付费无关,价格固定;敢给差评是建立信誉最快的方式。

### 冷启动(Roeu 的比喻:和自媒体起号一样需要时间)
1. 比赛前:2 到 3 篇 `demo_example` 示例测评填充首页(已有 2 篇)
2. Arena 1:主动免费测评 4 到 6 个参赛项目(`host_initiated`),测完邀请对方在 Arena 2 付费复测
3. Arena 2:开始收费

### 被否决的方案及原因(避免重复讨论)
| 方案 | 否决原因 |
|---|---|
| 通用爬虫 | 买家 agent 自带 web 能力,不会为此付费 |
| 服务目录 / 市场入口 | 信息量不大(约 30 个 agent,每个 agent 自己读得完);竞品 CITY 已在 QA room 免费提供"市场扫描" |
| 担保交易中介 | 积分经过中间人,计分方式不明,可能被视为刷分;思路已在 QA room 意外暴露 |
| 交易保险 | 理赔判断复杂,易被恶意索赔 |
| 纯带货(卖流量) | 单一房间无独占观众,已修正为"独立实测认证" |

竞品注意:**CITY**(city-test)在 QA room 提供免费市场扫描、价目、为卖家找客户、反击、实时排名。它做发现,我们做验证,可视为互补而非直接竞争。

## 4. 关键技术事实与决策

- **SharedNet `credits`(MCP)只返回汇总**(balance、granted、sent、received),没有逐笔记录和 memo。
- **SharedNet CLI 有 `ledger` 命令**可以逐笔查询,但在 Windows 原生环境报 `unsafe_credential_storage`。已在房间 #39 请 Codex 验证:先查 `--help` 有无绕过选项,再试 WSL(Roeu 已安装 WSL)。**结果待定,这是 Arena 2 能否收钱的关键。**
- 付款核验主方案:ledger 逐笔匹配(付款人、收款人、金额 5、memo = booking_id)。总额启发式默认关闭,且不得标为 transaction_verified。
- 付款窗口串行:同一时间只开一个 3 分钟窗口。
- 无法归属的款项:暂停收款、继续接预约,不猜测退款对象。**宁可暂停收款,不可错收;暂停的是收款,不是营业。**
- 退款:当前模型只支持固定 5 积分整单退款。金额不等于 5 的情况需比赛当天真实授权与适配,不能伪造为已完成。
- 当前账号积分余额为 0,开发期无法做真实付款测试。
- **主播运行方式**:arena 当天由 Roeu 本机一个 Claude Code 会话加剧本运行,会话内循环 `wait`,配合查 ledger 和调管理 API 的脚本。通用常驻运行器(M5)推迟到赛后。claude.ai 聊天界面无法充当主播,因为它按轮次工作,不能自主轮询。
- 采购与退款动作需 Roeu 在启动主播时明确授权。
