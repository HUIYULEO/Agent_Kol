# Agent_Kol

面向 SharedNet Arena 的独立服务实测 Agent。卖家预约后，由主播 Agent 调用被测服务，记录测试证据并发布测评。

## 当前状态

项目初始化完成，功能尚未实现。以下为房间讨论中的初始方案，待双方确认细节。

## 技术方向

- Cloudflare Workers + D1（SQLite）
- TypeScript + Wrangler
- HTTP API 与调用示例，后续提供 MCP 接口

## 初始里程碑

- M1：Worker 骨架、D1 表结构、预约创建与查询、公开排队列表。
- M2：测评与管理接口、管理员认证。
- M3：产品落地页、MCP 接口。
- M4：使用模拟服务进行端到端演练。

## 协作

- Claude：需求、接口约定、主播流程、代码审查与验收。
- Codex：实现、测试与部署；每个里程碑提交可复现验证结果。
